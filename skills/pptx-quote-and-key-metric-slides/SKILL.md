# Quote and Key Metric Slide Layouts

## When to use
Use this skill when highlighting customer testimonials, executive soundbites, core North Star metrics, IPO/quarterly revenue milestones, or key proof points.

## Design principles
- **Maximum Scale Disparity**: Make the focal number or quote headline massive (64–96 pt) and the supporting context crisp and small (16–20 pt).
- **Single Idea Isolation**: Dedicate the slide entirely to the metric or quote; do not contaminate the canvas with secondary charts or paragraphs.
- **Human Attribution**: Quotes must include person name, title, company, and ideally an avatar or company logo for authentic credibility.
- **Units and Delta Context**: Never show an isolated number without units (%, $, ms) and timeframe/benchmark context ("vs. prior year").

## Step-by-step workflow
1. **Select single hero data point**: Choose the one metric or testimonial that anchors the section narrative.
2. **Format hero metric layout**:
   - Number Size: 72–96 pt Bold in primary accent (`#2563EB` or `#059669`).
   - Label / Takeaway: 22–26 pt Bold (`#0F172A`) directly below the number.
   - Context Description: 15–16 pt Regular (`#475569`) explaining significance.
3. **Format executive quote layout**:
   - Quote Mark: 72 pt subtle graphic watermark (`#CBD5E1`) at `left = 1.0 in`, `top = 2.0 in`.
   - Quote Body: 28–36 pt Regular italicized or medium (`#0F172A`), wrapped within 10.0 in width.
   - Attribution: 16 pt Semi-Bold author name with 14 pt Regular job title and company.

## Specifics & examples
- **Hero Metric Coordinates (16:9 Canvas)**:
  - Big Number Box: `left = 1.2 in`, `top = 2.2 in`, `width = 10.5 in`, `height = 1.6 in`, `font = 84 pt Bold #2563EB` ("+142%").
  - Metric Headline: `left = 1.2 in`, `top = 3.9 in`, `width = 10.0 in`, `height = 0.8 in`, `font = 24 pt Bold #0F172A` ("Year-over-Year Enterprise Cloud ARR Growth").
  - Supporting Narrative: `left = 1.2 in`, `top = 4.8 in`, `width = 8.5 in`, `height = 1.2 in`, `font = 16 pt Regular #64748B` ("Driven by rapid adoption of autonomous security modules across Fortune 500 accounts.").

## Common mistakes
- Placing 6 competing metrics on a slide claiming each is "the hero", drowning all of them.
- Using 14 pt quotation text in a giant empty white slide, losing all dramatic visual impact.
- Omitting the timeframe or currency/percentage sign on large numeric callouts.

## Review checklist
- [ ] Hero statistic or quote dominates the slide with unmistakable visual hierarchy.
- [ ] Metric number is 64–96 pt with clear units (%, $, x).
- [ ] Quote includes full attribution (speaker name, title, organization).
- [ ] Canvas is uncluttered with zero competing charts or bulleted lists.
