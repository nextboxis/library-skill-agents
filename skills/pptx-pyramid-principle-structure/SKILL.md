# Pyramid Principle Structure for Decks

## When to use
Use this skill when preparing executive briefings, board presentations, investment memos, or strategy recommendations where stakeholders demand the answer upfront.

## Design principles
- **Answer First (BLUF)**: State the core recommendation or conclusion in the very first slide and in the action title of every subsequent slide.
- **Top-Down Logic**: Structure arguments hierarchically: Governing Thought -> Key Supporting Arguments -> Substantiating Evidence/Data.
- **Mutually Exclusive, Collectively Exhaustive (MECE)**: Ensure supporting pillars do not overlap in scope and together cover the entire problem space.
- **Executive Scannability**: An executive flipping through only the slide titles must understand the entire logical case without reading body text.

## Step-by-step workflow
1. **Formulate the Governing Thought**: Draft the single core conclusion that answers the executive's fundamental question.
2. **Identify MECE Supporting Pillars**: Group evidence into 3 distinct, non-overlapping themes (e.g., Financial, Operational, Strategic).
3. **Build the Slide Deck Hierarchy**:
   - Slide 1: Executive Summary (Governing Thought + 3 Pillars).
   - Slides 2–4: Pillar 1 evidence and supporting data.
   - Slides 5–7: Pillar 2 evidence and operational plan.
   - Slides 8–10: Pillar 3 risk analysis and mitigation.
   - Final Slide: Recommended decision and next steps.
4. **Draft Action Titles**: Write active, complete sentences for every slide title that summarize the pillar argument.
5. **Validate Vertical Logic**: Verify that every data point on a slide directly substantiates the claim in that slide's action title.

## Specifics & examples
- **Pyramid Executive Summary Slide (16:9 Canvas)**:
  - Header Action Title: `font = 32 pt Bold #0F172A` ("We Recommend Migrating to Antigravity Agents to Cut MTTR by 45%").
  - Governing Premise Card: `left = 0.8 in`, `top = 1.6 in`, `width = 11.733 in`, `height = 1.1 in`, `fill = #EFF6FF`, `border = 1 pt #BFDBFE`.
    - Text: `16 pt Semi-Bold #1E3A8A` ("Comprehensive analysis of 50 enterprise incidents confirms autonomous agent triage reduces triage time from 42 to 8 minutes.").
  - 3 MECE Pillar Cards: `top = 2.9 in`, `height = 3.6 in`, `width = 3.644 in`.
    - Pillar 1 (Financial): `left = 0.800 in` ("\$2.4M Annual OpEx Savings").
    - Pillar 2 (Reliability): `left = 4.844 in` ("99.99% Incident Containment").
    - Pillar 3 (Security): `left = 8.888 in` ("Zero Token Credential Leakage").

## Common mistakes
- Building a "mystery novel" deck that hides the recommendation until slide 25.
- Creating overlapping supporting categories that confuse stakeholders during Q&A.
- Using topic titles like "Financial Analysis" instead of active claims like "Financial Analysis Projects 3.2x ROI".

## Review checklist
- [ ] Recommendation is clearly stated on slide 1 and in every slide title.
- [ ] Supporting categories are strictly MECE (non-overlapping and complete).
- [ ] Slide titles alone form a coherent, end-to-end executive narrative.
- [ ] Every slide data element directly supports that slide's specific claim.
