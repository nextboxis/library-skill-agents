# Building Color Palettes for Slides

## When to use
Use this skill when starting a new deck from scratch, converting raw brand guidelines into slide-ready colors, or fixing clashing presentation palettes.

## Design principles
- **Functional Color Roles**: Colors in business slides are functional, not decorative. Every color must have a designated purpose.
- **Restraint Over Variety**: A professional palette requires only 4–5 colors: Background, Primary Text, Neutral Surface, Primary Accent, and Alert Accent.
- **Avoid Saturated Backgrounds**: Vibrant background colors cause severe eye fatigue; keep canvas colors neutral (clean white, off-white, or deep dark slate).
- **Semantic Consistency**: Red always means negative/risk, green always means positive/growth; never invert these meanings within a deck.

## Step-by-step workflow
1. **Choose canvas background**: Select crisp light canvas (`#FFFFFF` or `#F8FAFC`) or executive dark canvas (`#0F172A`).
2. **Define primary typography tone**: Pair with high-contrast text tone (`#0F172A` for light, `#F8FAFC` for dark).
3. **Select neutral surface tint**: Create container card surface color with slight contrast against canvas (`#F1F5F9` on white).
4. **Assign primary brand accent**: Choose one bold, authoritative brand color (`#2563EB` Royal Blue) for headers, key metrics, and charts.
5. **Assign functional semantic accents**: Reserve green (`#16A34A`), amber (`#D97706`), and red (`#DC2626`) strictly for data callouts and status.

## Specifics & examples
- **Corporate Tech Palette (Light Theme)**:
  - Canvas: `#FFFFFF` (Pure White).
  - Neutral Surface / Cards: `#F8FAFC` (Slate 50).
  - Primary Text: `#0F172A` (Slate 900 - 15.4:1 contrast).
  - Secondary Text: `#475569` (Slate 600 - 7.1:1 contrast).
  - Primary Accent: `#2563EB` (Blue 600 - for anchors and focus).
  - Positive Semantic: `#16A34A` (Green 600 - for growth/targets).
  - Critical Semantic: `#DC2626` (Red 600 - for risks/losses).
- **Executive FinTech Palette (Dark Theme)**:
  - Canvas: `#0F172A` (Deep Slate).
  - Neutral Surface / Cards: `#1E293B` (Slate 800).
  - Primary Text: `#F8FAFC` (Off White).
  - Secondary Text: `#94A3B8` (Muted Slate).
  - Primary Accent: `#38BDF8` (Sky Blue 400).
  - Positive Semantic: `#34D399` (Emerald 400).

## Common mistakes
- Using 8 different bright colors across slides, turning the deck into visual noise.
- Using bright red as a primary brand accent color for non-critical headings, causing false panic.
- Using low-contrast pastels for text or data points.

## Review checklist
- [ ] Palette contains no more than 5 functional colors.
- [ ] Every color has a documented role (canvas, text, surface, accent, status).
- [ ] Primary text achieves at least 4.5:1 contrast against canvas and card surfaces.
- [ ] Semantic red and green are reserved exclusively for negative and positive data.
