# Summary and Closing Slide Layouts

## When to use
Use this skill when delivering final presentation takeaways, board decision requests, next steps action plans, Q&A transitions, or contact closing frames.

## Design principles
- **Decisive Call to Action (CTA)**: The closing slide should tell the audience exactly what decision, approval, or follow-up is expected.
- **Rule of Three Takeaways**: Summarize core arguments in 3 high-impact cards or check items; never regurgitate the entire presentation.
- **Action Owner and Timeline**: For next steps, explicitly bind tasks to owners and target completion dates.
- **Clear Contact Channels**: Replace generic "Thank You" slides with relevant next steps, contact info, and repository/document links.

## Step-by-step workflow
1. **Determine closing intent**: Decide whether the slide is an Executive Decision Request, Next Steps Action Plan, or Contact / Q&A frame.
2. **Structure 3-card summary**:
   - Card 1: Key Finding / Strategic Problem resolved.
   - Card 2: Recommended Solution and resource commitment.
   - Card 3: Expected ROI and delivery milestone.
3. **Add Action Next Steps Table**:
   - Columns: Action Item (5.0 in), Owner (2.5 in), Target Date (2.0 in), Status (1.5 in).
4. **Format Contact / Q&A footer**:
   - Provide email, Slack/Teams channel, or documentation link in 14 pt bold text at bottom right.

## Specifics & examples
- **Next Steps Action Plan Layout (16:9 Canvas)**:
  - Header Action Title: `left = 0.8 in`, `top = 0.6 in`, `font = 36 pt Bold #0F172A` ("Next Steps & Implementation Timeline").
  - Subtitle: `left = 0.8 in`, `top = 1.25 in`, `font = 18 pt Regular #64748B` ("Key milestones required for Phase 1 production cutover.").
  - Container Card: `left = 0.8 in`, `top = 1.8 in`, `width = 11.733 in`, `height = 4.6 in`, `fill = #FFFFFF`, `border = 1 pt #E2E8F0`.
  - 3 Summary Action Rows:
    - Row 1: `top = 2.2 in`, "Finalize security architecture review", Owner: "SecOps", Date: "Nov 15".
    - Row 2: `top = 3.2 in`, "Deploy pilot cluster to staging environment", Owner: "DevOps", Date: "Nov 30".
    - Row 3: `top = 4.2 in`, "Executive steering committee go/no-go signoff", Owner: "Sponsors", Date: "Dec 10".

## Common mistakes
- Ending on a blank slide that simply says "Questions?" with no lingering summary or contact information.
- Packing 12 dense bullet points into the summary slide, overwhelming audience recall.
- Omitting owners and deadlines from next steps slides, turning decisions into ambiguous intentions.

## Review checklist
- [ ] Summary focuses on 3 decisive takeaways rather than an exhaustive retrospective.
- [ ] Next steps clearly assign owners and target completion dates.
- [ ] Contact details and reference documentation links are clearly legible.
- [ ] Closing slide directly drives the requested executive decision or call to action.
