# Color for Data and Emphasis

## When to use
Use this skill when highlighting an outperforming product, drawing eyes to a strategic bottleneck, or guiding executive focus across dense data tables and charts.

## Design principles
- **Pre-attentive Visual Processing**: Color is the fastest visual cue human vision detects. A single colored bar in a grey chart is processed in under 100 milliseconds.
- **The Grey-First Rule**: Color all data elements neutral grey (#CBD5E1) by default; apply saturated color only to the single data series carrying the core insight.
- **Consistent Semantic Coding**: Always map green (#16A34A) to positive performance, red (#DC2626) to risk/loss, and blue (#2563EB) to strategic baseline.
- **Never Rely on Color Alone**: Always reinforce color coding with directional symbols (+/-, up/down arrows) for color-blind accessibility.

## Step-by-step workflow
1. **Identify the hero data point**: Find the single bar, line, or row that proves the slide's action headline.
2. **De-saturate all background data**: Recolor competing series, past historical periods, and baseline rows in soft slate grey (#94A3B8 or #CBD5E1).
3. **Apply focal accent color**: Color the hero series in bold brand blue (#2563EB) or positive green (#16A34A).
4. **Attach direct data labels**: Place exact values directly above the accented element, eliminating the need to look back and forth to an axis.
5. **Add redundant shape indicators**: Pair negative red values with a downward triangle (▼) and positive green with an upward triangle (▲).

## Specifics & examples
- **Comparative Bar Chart Palette**:
  - Baseline/Competitor Bars: `#E2E8F0` (Slate 200).
  - Prior Year Performance: `#94A3B8` (Slate 400).
  - Target Company / Outperformer: `#2563EB` (Blue 600 - High Focus).
- **Status Indicators (Hex Codes)**:
  - On Track / Healthy: `#16A34A` (Green 600) + ▲ symbol.
  - At Risk / Caution: `#D97706` (Amber 600) + ◼ symbol.
  - Off Track / Critical: `#DC2626` (Red 600) + ▼ symbol.
- **Data Table Highlight**:
  - Outperforming Row: Fill `#EFF6FF` (5% blue tint), Left Border `3 pt solid #2563EB`.

## Common mistakes
- Assigning random rainbow colors to 6 different bars when they all represent the same metric across quarters.
- Using red for positive metrics because it matches a corporate brand color.
- Leaving all chart bars the same saturated color, forcing viewers to search for the highlight.

## Review checklist
- [ ] Baseline and historical data points are rendered in neutral grey.
- [ ] Exactly one prominent color highlights the core takeaway or target metric.
- [ ] Semantic colors (green/red) align with positive/negative business meaning.
- [ ] Color highlights are supplemented with text labels or symbols for accessibility.
