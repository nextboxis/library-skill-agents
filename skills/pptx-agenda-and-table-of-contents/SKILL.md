# Agenda and Table of Contents Slides

## When to use
Use this skill when introducing multi-section presentations, orienting executive audiences on meeting flow, or recapping progress during long working sessions.

## Design principles
- **Orientation Over Redundancy**: An agenda is not a table of contents to read aloud; it provides a mental roadmap of the key decision checkpoints ahead.
- **Numbered Modular Cards**: Numbered cards (01, 02, 03) create visual rhythm and feel more structured than a plain vertical bullet list.
- **Highlighting Active Section**: When reusing the agenda as a progress tracker throughout the deck, dim past/future sections and highlight the current topic.
- **Limit to 3–5 Core Topics**: Audiences cannot track 8 disparate agenda items; consolidate items into 3 to 5 logical phases.

## Step-by-step workflow
1. **Consolidate agenda topics**: Group the presentation content into 3, 4, or 5 primary sections.
2. **Draft action-oriented labels**: Write topic names that convey value (e.g., "01 Strategic Context & Market Shift" instead of "01 Intro").
3. **Choose layout structure**:
   - For 3–4 items: Use horizontal cards spaced evenly across the 11.7 in usable width.
   - For 5 items: Use a vertical stack with numbered left-aligned pills.
4. **Style numbers as design features**: Format numbers (01, 02, 03) in 28–36 pt bold accent color (#2563EB) to establish clear order.
5. **Add brief descriptive subtitles**: Add a 13–14 pt explanatory line beneath each agenda title describing what will be covered.

## Specifics & examples
- **3-Card Horizontal Agenda Layout (16:9 Canvas)**:
  - Card Width: `3.644 in`, Card Height: `4.500 in`, Card Gap: `0.400 in`.
  - Card 1: `left = 0.800 in`, `top = 1.800 in`.
  - Card 2: `left = 4.844 in`, `top = 1.800 in`.
  - Card 3: `left = 8.888 in`, `top = 1.800 in`.
  - Number Callout: `32 pt Bold #2563EB`.
  - Section Title: `20 pt Semi-Bold #0F172A`.
  - Section Scope: `14 pt Regular #475569`.
- **Card Background**: `#F8FAFC`, Border `1 pt solid #E2E8F0`, Radius `0.12 in`.

## Common mistakes
- Listing 10 granular agenda items, overwhelming the audience before the presentation begins.
- Reading through the entire agenda word-for-word instead of speaking to the overarching narrative arc.
- Using a plain bulleted list on an otherwise richly designed presentation.

## Review checklist
- [ ] Agenda contains between 3 and 5 logical sections.
- [ ] Numbered indicators (01, 02, 03) clearly establish the progression.
- [ ] Each section has an action-oriented title and a brief scope description.
- [ ] Spacing between agenda cards or list items is mathematically uniform.
