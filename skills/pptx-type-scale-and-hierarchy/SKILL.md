# Type Scale and Hierarchy for Slides

## When to use
Use this skill when defining slide master font sizes, resizing overflowing text, and establishing clear typographical relationships across presentation components.

## Design principles
- **Strict Size Step Intervals**: Typography scales should follow a defined ratio (1.25× Major Third or 1.33× Perfect Fourth) rather than arbitrary point steps.
- **The 3-Second Readability Rule**: Key takeaways must be legible to attendees sitting in the back row of a physical room or watching on a mobile screen.
- **Minimum 14 pt Floor**: Never allow body text or captions to drop below 14 pt on content slides (10–12 pt reserved strictly for legal disclaimers).
- **Weight as Hierarchy Multiplier**: Combine size jumps with weight changes (Bold to Regular) to establish unmistakable reading order.

## Step-by-step workflow
1. **Set action title scale**: Size slide action titles between 36 pt and 44 pt Bold based on title length (target: 1–2 lines).
2. **Set category eyebrow**: Size section category trackers above titles at 12–14 pt Semi-Bold, uppercase with 1.2 pt letter spacing.
3. **Set card headers**: Size container card headers at 20–24 pt Semi-Bold.
4. **Set body copy**: Standardize body paragraphs and primary bullets at 15–18 pt Regular.
5. **Set KPI hero numbers**: Size big standalone statistics at 44–64 pt Bold for dramatic focal impact.

## Specifics & examples
- **Standard 16:9 Type Scale Matrix**:
  - Category Eyebrow: `12 pt Semi-Bold` (Uppercase, `#64748B`).
  - Action Title: `36–40 pt Bold` (Leading 1.15x, `#0F172A`).
  - Subtitle / Context Line: `20–22 pt Regular` (`#475569`).
  - Container / Card Header: `20 pt Semi-Bold` (`#1E293B`).
  - Primary Body Text: `16–18 pt Regular` (`#334155`).
  - Secondary Bullets / Details: `14–15 pt Regular` (`#475569`).
  - Hero Data Metric: `48–60 pt Bold` (`#2563EB`).
  - Footnote / Data Source: `11–12 pt Regular` (`#94A3B8`).

## Common mistakes
- Shrinking title text down to 24 pt to fit 4 lines of rambling explanation.
- Using 10 pt font for bullet points so that an entire whitepaper can fit onto one slide.
- Setting body text and card titles to nearly identical sizes (e.g., 18 pt vs 16 pt).

## Review checklist
- [ ] Action titles are set to 36–44 pt Bold.
- [ ] Primary body copy is set to 16–18 pt Regular.
- [ ] No primary body or table text drops below 14 pt.
- [ ] Hero metrics are noticeably scaled to 48 pt or larger for visual impact.
