# Managing Freelance Client Expectations & Milestones

## When to use
Use this skill throughout active freelance and consulting projects to ensure smooth collaboration, zero unpleasant surprises, and timely approvals.

## Core principles
- **Proactive Over-Communication**: Clients get anxious when there is silence. Send a weekly async update every Friday even if there is nothing dramatic to report.
- **The Scope Creep Change-Order Rule**: When a client asks 'Can we quickly add a little feature?', never say no rudely and never do it for free. Say: 'Yes, absolutely! Let me draft a quick Change Order showing the additional cost and timeline adjustment.'
- **Loom Video Demos over Lengthy Emails**: A 3-minute video showing the working feature in action creates instant clarity and enthusiasm, cutting down endless email threads.
- **Formal Milestone Sign-Offs**: Require written sign-off (email or client portal) at the completion of each phase before beginning the subsequent phase.

## Step-by-step workflow
1. Establish a single communication channel: dedicated Slack channel or weekly email digest (avoid random WhatsApp/text messages).
2. Send weekly Friday update: 1) What was completed, 2) What is planned next week, 3) Blockers requiring client input.
3. Record 2–3 minute Loom walk-through when delivering major features.
4. When new requests arise: evaluate against SOW; issue a formal Change Order if out of scope.
5. Request formal written milestone sign-off and issue milestone invoice.
6. Maintain an asynchronous project dashboard (Trello / Linear / Notion) showing ticket progress.

## Specifics & examples
- **The Scope Creep Pivot Script**:
  *Client*: 'Hey, can we also add social login with Google and Apple to this sprint?'
  *Contractor*: 'That's a great feature and will definitely improve user onboarding! It's outside our current Phase 1 SOW which focuses on email auth. I can definitely build it—would you like me to create a quick Change Order for \$1,200 and add 3 days to our timeline, or would you prefer we log it as a priority for Phase 2 after our core launch?'
- **Friday Update Format**:
  - ✅ *Completed*: User registration API, password hashing, JWT token rotation.
  - ⏳ *In Progress*: Stripe subscription webhooks.
  - 🛑 *Needs Attention*: Awaiting your Stripe sandbox API keys to test checkout.

## Common mistakes & pitfalls
- Absorbing endless 'small tweaks' for free until the project runs 2 months behind schedule and unprofitable.
- Disappearing for 3 weeks without updating the client, causing panic and micromanagement.
- Using multiple fragmented communication channels (email, text, Slack, phone calls).

## Verification checklist
- [ ] Weekly async progress updates sent consistently on schedule.
- [ ] New out-of-scope requests routed through formal written Change Orders.
- [ ] Written milestone sign-offs obtained before advancing to subsequent phases.
